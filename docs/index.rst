|addon| for the |NCS|
#####################

The |addon| for the |NCS| provides support for developing applications that use combined solution based on Matter and Zigbee technologies.

.. note::
   The |addon| is provided at an `Software maturity levels`_ level of maturity.

The add-on currently provides a proof-of-concept platform design where Zigbee and Matter time-share the 802.15.4 radio on a single SoC.
See :ref:`matter_zigbee_platform_design` for the architecture overview and :ref:`matter_zigbee_samples` for sample applications.

This add-on requires the `Zigbee R23 add-on`_ and the Matter stack from the |NCS|.
