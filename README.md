# Matter and Zigbee combined solution for nRF Connect SDK

The Matter and Zigbee add-on for nRF Connect SDK provides combined Matter and Zigbee application support on a single SoC.

## Getting started

To get started with Matter and Zigbee add-on for nRF Connect SDK, follow [documentation](https://nrfconnectdocs.nordicsemi.com/addons/ncs-matter-zigbee/latest/index.html).
